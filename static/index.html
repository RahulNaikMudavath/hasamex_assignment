SYSTEM ARCHITECTURE

1. End-to-End Pipeline

The application implements a decoupled, high-performance architecture separating ingestion, verification, retrieval, and presentation:

  • Turn Segmentation Engine: Pre-processes raw transcripts into timestamp-anchored conversational turns, calculating speaker roles, word counts, and temporal offsets.
  • Verbatim Verification Layer: Character-level substring validator verifying quotes against raw source text with 100% exact fidelity.
  • Dual Execution Mode: Seamlessly operates offline via deterministic grounded heuristics, or augments answers with Google Gemini / OpenAI when an API key is provided.
  • Interactive Deep-Linking: Bidirectional UI synchronization linking analytical insights, matrix answers, and Q&A citations directly to dialogue turns.
MODEL SELECTION

2. Model Selection & Trade-offs

We designed the system with tiered intelligence layers to balance precision, latency, and operational cost:

  • Primary LLM (Gemini 2.5 Flash / GPT-4o-mini): Exceptional instruction following, rapid sub-second latency (TTFT < 350ms), and large context windows for processing multi-call dossiers.
  • Built-in Offline Engine: Token-indexed verbatim extraction ensuring the app works out of the box with zero external dependencies or API latency.
  • Deterministic Verification: LLMs are never allowed to emit citations without verification against the ground truth string span.
CITATION HANDLING

3. Timestamp & Quote Attribution

How timestamps and exact quotes are extracted and guaranteed:

  • Timestamp Anchoring: Turns are segmented strictly at `MM:SS` boundaries. Every quotation inherits the exact speaker turn timestamp.
  • Fuzzy-to-Exact Verification: Any extracted quote is checked via string search. If modified, the engine flags it and highlights the verbatim source turn.
  • Deep-Link Traversal: Clicking a citation dynamically activates the Transcript Explorer, scrolls to the turn's offset, and triggers a visual pulse animation.
AI SAFETY

4. Hallucination Reduction Strategy

Crucial safeguards addressing the "Do not invent information" mandate:

  • Closed-Domain Constrained Prompting: The LLM is restricted to a "closed world" schema where extrapolations outside provided turns are strictly prohibited.
  • Out-of-Domain Guardrail: Keyword and semantic overlap thresholds detect queries unrelated to the case (e.g. robotic surgery in Japan) and produce explicit refusals.
  • Confidence Scoring: Each response calculates a grounding confidence score based on the proportion of claims supported by verified verbatim text.
SCALING ROADMAP

5. Scaling from 3 to 30+ Transcripts (Production Enterprise Blueprint)

To scale from 3 calls to 30, 300, or 3,000 calls across multiple projects and geographies, the architecture scales via the following enterprise patterns:

A. Vector Storage & Hybrid Retrieval

Replace in-memory indexing with a production vector database (e.g. pgvector or Qdrant). Use Hybrid Search (BM25 lexical search + dense embedding vectors) with metadata filtering by region, hospital type, and expert role.

B. Hierarchical Map-Reduce Synthesis

For cross-call thematic analysis across 30+ calls, run parallel Map extractions per call against the interview guide, followed by a hierarchical Reduce clustering step that groups consensus topics and outliers using embeddings.

C. Automated Diarization Pipeline

Integrate automated audio ingestion via Whisper / Google Speech-to-Text with speaker diarization, automatically generating timestamped JSON transcripts with word-level confidence.

D. Continuous Evaluation & RAGAS

Deploy continuous evaluation pipelines using frameworks like RAGAS to automatically monitor faithfulness, answer relevance, and context recall across evolving interview packs.
